- **视频页的「在 B站 观看」指向 `bilibili.com/video/example` 占位链接** → 占位链接不渲染，改为「视频链接待发布」；占位 URL 也不进 JSON-LD
- **配图文件名带空格 → 浏览器请求被截断 → 404 裂图**：`public/images/image 20260510111054.jpg` 这类文件名里的空格
  在浏览器请求时会变成 `%20` 之外的断裂形态。方案 P0-1 只覆盖了「文件是不是真图」，没覆盖「路径能不能被正确请求」。
  修法：`src/lib/covers.ts` 的 `resolveCover` 统一走 `encodeURI`（**两套仓库同一个 bug，都修了**）
- **og:image 的同源漏洞（只修一半等于没修）**：上一条只修了 `<img src>` 那条路（`resolveCover`）。
  但 **`og:image` / `twitter:image` / JSON-LD 的 `image` 走的是另一条出口** —— `src/lib/seo.ts` 的 `absoluteUrl`，
  它拿到的是**原始 cover 字段**，没有编码。结果是：
  `<meta property="og:image" content="https://digiwild.cc/uploads/works/finance-crm/image 20260510111054.jpg"/>`
  —— **URL 里有裸空格，非法 URL**。微信 / 推特 / 飞书的抓取器会在空格处截断，拉不到图，**分享卡片直接裂**；
  而 `<img>` 在页面里是正常的，**肉眼看页面完全发现不了**。
  修法：`absoluteUrl` 统一编码路径；新增 `encodeUrlPath` 辅助函数 —— 按 `%XX` 切段，
  **已有转义原样保留**（不能直接 `encodeURI` 整条丢进去，`encodeURI` 会把 `%` 编成 `%25`，`%20` 会变 `%2520`）。
- **字体外链**：`styles.css` 原本从 `fonts.gstatic.com` 拉 Fraunces/Inter/JetBrains Mono（大陆基本加载失败）→ 改全系统字体栈，零外部请求
- **删死代码**：`About.tsx`（含「12,000+ 名读者」假数字、无人引用）、`AIChatSection.tsx`（承诺一个没配置的 AI 助手）、`FloatingChatButton.tsx`（指向无关外站）；同时清掉 `public/images/` 与 `src/assets/` 里 1.7MB 冗余图片

### 构建环境修复（SMB 挂载）

本仓库在 `/Volumes/Agent_Space`（**SMB 网络挂载**）上，原 `node_modules` 残缺
（211 个条目但缺 `@tanstack/react-router` / `typescript`，`.bin` 为空）→ 根本跑不起 build。
`npm ci` 在 SMB 上 20 分钟装不完。做法：

1. 同卷重命名 `mv node_modules .node_modules.broken`（**1.5 秒**）—— 同卷 `mv` 是元数据操作，
   跨设备会退化成全量拷贝（实测 182MB 拷了 29 分 56 秒）
2. 在本地盘 `/Users/qiang/.cache/digiwild-deps` 装一次完整依赖
3. `ln -sfn /Users/qiang/.cache/digiwild-deps/node_modules node_modules` 软链回 SMB 目录

之后**在原目录直接 `vite build` 即可**，不再需要 rsync 中转。

> ⚠️ **但不要在 SMB 上原地构建。** 实测 `vite build` 在 SMB 目录里跑 8 分钟零产出，
> `sample` 抓下来 90% 时间卡在 `node::fs::Stat` / `realpath` / `statfs` ——
> rollup 解析每个 import 都要在网络上往返一次 stat，**SMB 的 stat 往返是致命的**。
> 正解：把源码 rsync 到本地盘（如 `/tmp/build-a`）构建，再把 `dist/` + `public/` 生成物 rsync 回来。
> 软链解决的是「依赖装不上」，解决不了「源码在慢盘上」。

### B. 修一个会让首页整块隐形��严重 bug

**现象**：产物 HTML 看着完全正常，但浏览器里首页首屏（标题、副标题、CTA、头像）
**整块隐形**，只剩导航栏。

**根因链**：

1. `IntentPaths.tsx` 里整行用 `<a>` 包裹，行内又嵌了路径链的 `<a>` → **`<a>` 套 `<a>`**
2. 这是非法 HTML，浏览器解析器会**自动拆开外层 `<a>`** → 客户端 DOM 与 React 预期不一致
3. → **hydration 失败（React #418）**，React 放弃水合并在客户端重建整棵树
4. → framer-motion 的 `initial={{ opacity: 0 }}` 永远不解除 → **首屏隐形**

**修法**：改用「拉伸链接」模式 —— 外层是 `<div>`，标题是主链接并用
`after:absolute after:inset-0 after:content-['']` 撑满整行，路径链用
`relative z-10` 浮在拉伸层之上，各自仍可点。整行可点 + 路径链可点 + HTML 合法。

**防回归**：`scripts/verify-seo.mjs` 新增 `hasNestedAnchor()` 静态断言，
